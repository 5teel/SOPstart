Block Library

Reusable hazards, PPE, steps and emergency blocks. Each block can belong to any number of departments — tag a burn hazard to both Forming and Maintenance, or mark a block All departments to make it org-wide.

Many-to-many. A block is linked to a set of departments, not one bucket. The “Burn hazard” row below shows the editor open — tick Forming + Maintenance and it appears in both. All departments is its own toggle for truly org-wide blocks (evacuation, hi-vis). Filtering by a department returns every block tagged to it, plus all org-wide blocks.
