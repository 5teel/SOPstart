## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Comment quotes the forbidden literal | Four executors wrote a comment naming the exact string a grep guard forbids and tripped the guard on a green change | advisory | Describe absent patterns in words; guards strip comments (`stripComments`) — CLAUDE.md 2026-09-28 |
| Timeouts raised to diagnose an empty locator | A `click()` on a locator matching zero elements waits out the whole budget; raising `test.setTimeout` only made it slower | advisory | Assert `toHaveCount(1)` with a short timeout before any other change — CLAUDE.md 2026-09-28 |
| Full suite looped during a gate | Live-Supabase probes share one Auth OTP budget; three back-to-back runs turned every phase's RLS probe red | advisory | Run the suite ONCE per gate; compare non-live failures to `51-BASELINE-FAILURES.md` — CLAUDE.md 2026-09-28 |
| Mount-effect `router.replace` on Next 16.2.1 | Navigation while a server action is in flight orphans the next queued action; the router hangs and even `useViewport` never flips | advisory | Server-side redirects for legacy URLs; upgrade Next to ≥16.3 — CLAUDE.md 2026-09-29 |
