<objective>
Close verification gap **CR-01 (Blocker)**: `deleteSop` in `src/actions/sops.ts:340-355` runs six service-role (RLS-bypassing) deletes filtered only by `sop_id`, with no check that the SOP belongs to the caller's organisation. Because a Next.js Server Action is a directly-invokable POST endpoint, any admin of any org can pass an arbitrary `sopId` and permanently destroy another organisation's SOP plus its sections, parse jobs, assignments, video jobs, and notifications. Purpose: Make the shipped Tools-menu delete safe to expose (SC-6's own deliverable) and add a regression test so this class cannot silently ship green again.
Output: `deleteSop` guarded by an org-ownership check; a live cross-org rejection test + source-contract guard-ordering assertions registered in the `phase33` project.
</objective>
