<objective>
The canvas half of SIT-02/SIT-03: a presentational Konva component that renders the scene at natural size, pans, zooms to the cursor, fits on resize, draws polygons, selects them and drags their corners — emitting scene-pixel coordinates through callbacks. It owns no data and calls no server action; `SiteWorkspace` (51-05) owns state and saving.

Purpose: isolate the one genuinely new, canvas-heavy piece so it builds in parallel with the schema (51-02) and the actions (51-03), and so Konva stays in one lazily-loaded chunk (D-08).

Output: `SiteEditor.tsx` (default export, props `SceneEditorProps` from `src/lib/site/scene.ts`), `SiteEditorLoader.tsx`, and the activated canvas spec.

Decisions implemented: D-09 (Konva; pan by dragging empty space, wheel zoom-to-cursor, Draw machine clicks, close on first vertex or double-click, select shows fill + handles, drag a vertex — delete/rename/department/save live in the workspace), D-02 (scene-pixel output only), D-08 (dynamic ssr:false loader). The Phase 26 annotation editor has no pan/zoom to reuse (RESEARCH), so the maths is the sketch's (`fitView`/`zoomAt` in scene.ts, unit-tested in 51-01). Discretion: vertex handle radius 7 screen px (constant on screen at any zoom), close-snap 10 screen px, zoom clamp [fit × 0.5, 4].
</objective>
