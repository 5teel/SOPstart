<objective>
Extract the `/admin/sops` list query — every filter branch, the draft-triage ordering, the department/collection id resolution, the rail counts, the scope-department counts and the `MillerSop[]` row mapping — out of the server page body (`src/app/(protected)/admin/sops/page.tsx:137-458`) into one self-guarding server action, plus two plain modules for the pure helpers and flag-display maps that a `'use server'` file may not export.

**Rendering model for this phase (D-03, stated here and honoured by every later plan):** `/sops` stays a **client component** with its worker data layer untouched, and the three admin views become `next/dynamic({ ssr: false })` **client lenses** gated by `useIsAdmin()`, fetching through server actions. This is the second ROADMAP-sanctioned shape ("keep the list client-side and code-split the admin lenses"), chosen because the worker path already has a working offline/Dexie data layer that D-03 requires be preserved verbatim, because `listGovernanceQueue` / `listOrgTree` / `listGrants` are already `'use server'` actions callable from a client `useQuery` (verified at plan time — all four self-guard via `requireAdminContext()`), and because `next/dynamic({ ssr: false })` is the exact mechanism SB-LINE-06's existing gate already knows how to verify. This plan is the first half of that model: the data side.

**This plan does not touch `src/app/(protected)/admin/sops/page.tsx`.** The helpers are COPIED into the new plain modules and the old page keeps its own copies until 41-06 replaces its whole body with a redirect shim. Four waves of duplication buys zero file-overlap between plans; it is deliberate, not an oversight.

Purpose: SUR-02 needs the admin views as lenses on a client page; that is only safe if the ~200 lines of filter logic move intact rather than being re-derived by eye (RESEARCH § Don't Hand-Roll — the `departments=none` audience edge case, the status/dept/collection XOR and the `NO_MATCH_ID` sentinel are all easy to silently drop).
Output: `listAdminSopRows`, `src/lib/sop-list/admin-rows.ts`, `src/lib/governance/flag-display.ts`.
</objective>
