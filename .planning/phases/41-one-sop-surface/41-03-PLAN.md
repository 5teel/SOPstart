## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| any authenticated session → `listAdminAccessData` | this action returns the ENTIRE org model, every access grant and every collection — the highest-value payload in the phase, and the page-level admin redirect in front of it is being deleted |
| client-supplied `?sop=` id → `ensureSopCollections` (a WRITE path) | a deep-link param reaches a function that can CREATE collection rows |

| T-41-01c | Elevation of Privilege | `ensureSopCollections` reached via `?sop=` | transfer | `ensureSopCollections` already self-guards (`requireAdmin()` → `requireAdminContext()`) and `ensureSopCollectionsForOrg` re-verifies `sops.organisation_id === orgId` before any write (2026-06-15 self-enforced org scope, verified at plan time); this plan adds a second guard in front of it rather than relying on that alone |
| T-41-01d | Information Disclosure (cross-tenant) | org tree / grants / collections reads | transfer | `listOrgTree` and `listGrants` each filter `.eq('organisation_id', ctx.organisationId)` internally (verified at plan time); the raw `collections` / `member_departments` / `sop_collections` reads go through the session RLS client, and `WiringPatchBay` only indexes department ids present in the caller's own tree (`page.tsx:266-267`) |
