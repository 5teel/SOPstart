<objective>
Add smart-next predictions with auto-dismissing ghosts (R4) — the sketch-validated behaviour. Confident, content-adjacent predictions (Hazard→PPE, Measurement→Decision, Step→Measurement) surface as an inline dashed-purple ghost that accepts on Tab/click and self-manages visibility. This reuses the `SMART` map from the inserter (26-08) so predictions and the inserter's smart row share one source.

The strict rules (from the sketch / UI-SPEC):
- Render a ghost after block `i` iff `SMART[type(i)]` exists AND `type(i+1) !== predictedType` (self-suppress when redundant).
- Exactly one "live" ghost near viewport-center; others `.dim` (opacity .3); a ghost scrolled past (`bottom < 64px`) becomes `.gone` permanently.
- Tab accepts the live ghost; typing inside a block `.gone`s all ghosts except the one immediately after it.
- **Performance rule (RESEARCH):** rAF-throttled class toggles on refs — NEVER re-render the document on scroll.

Purpose: fast, non-nagging prediction that never renders a redundant suggestion.
Output: `useSmartGhosts`, `GhostRow`, ghost injection in `EditableDocument`.
</objective>
