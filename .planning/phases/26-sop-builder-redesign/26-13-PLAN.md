<objective>
Close the absorbed Phase 17 arc (D-03, slice 3): persist annotation scenes and bake them for the worker read path. Two pieces:
- **`saveAnnotation` server action** — writes `scene` + `natural_width/height` to `sop_image_annotations`. The table has NO authenticated write policy (26-05), so this uses `createAdminClient()` (service-role) and MUST self-enforce `row.organisation_id === caller.orgId` + `.eq('organisation_id', …)` on the write (recurring bug family — CLAUDE.md 2026-06-15/26). Org id from `parseJwtPayload` (`src/lib/supabase/jwt.ts`), NEVER `atob`. Async-only `'use server'` (no pure/sync exports — CLAUDE.md 2026-06-27; run a real `npm run build`).
- **Bake-on-publish** — at publish, the admin client `stage.toDataURL()` → a content-versioned baked PNG at `sop-images/baked/{sop}/{image}.v{N}.png` (beats CDN cache), writes `baked_storage_path`/`baked_at`. The worker read path serves the baked `<img>` ONLY — **never imports Konva** (D-03 HARD constraint, R8).

Purpose: durable, non-destructive annotations + a flat baked image workers render without Konva.
Output: `saveAnnotation`, `bake-on-publish`, worker baked-PNG read, org-scoped + Konva-isolated.
</objective>
