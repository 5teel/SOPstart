### `supabase/migrations/00040_agent_metadata_schema.sql` (migration, CRUD/append-only)

**Analog:** `supabase/migrations/00039_sop_image_annotations.sql` (full text read above) + `00038_phase23_schema.sql` for `ai_field_proposals` shape.

**Copy verbatim:**
- Table shape: `id uuid pk`, `organisation_id uuid not null references organisations(id) on delete cascade`, timestamps.
- RLS: `alter table ... enable row level security;` then **one** SELECT policy `using (organisation_id = public.current_organisation_id())` — direct column comparison, **zero** `exists (select ... from public.sops)` subqueries (42P17 recursion risk, CLAUDE.md 2026-05-13).
- **No authenticated INSERT/UPDATE/DELETE policy** — comment explaining writes go through `createAdminClient()` in a server action that self-enforces org-scope.
- Indexes: `idx_<table>_org on (organisation_id)` + FK indexes.
- `create extension if not exists vector;` once at top of file, then `vector(1024)` columns + `using hnsw (embedding vector_cosine_ops)` index (per RESEARCH.md Pattern 1, Assumption A2 — confirm 1024 dim against actual Voyage model chosen before backfill runs).
- End each table with a `comment on table ...` summarizing the security model, matching 00039's closing comment exactly in style.

**RESEARCH.md already has the exact SQL to copy** (Architecture Patterns → Pattern 1, lines 226-257 of 26.5-RESEARCH.md) — use it as the literal starting point for `sop_agent_metadata`; shape `block_agent_metadata`, `agent_memory`, `agent_learning_proposals` identically (same RLS/index/comment shape), varying only columns.

### `src/actions/agent-layer.ts` (server actions, CRUD)

**Analog:** `src/actions/departments.ts` full `requireAdmin()` helper (lines 33-57) — copy the shape exactly:

```typescript
// src/actions/departments.ts lines 33-57
type AdminCtx = {
  supabase: any
  user: { id: string }
  role: string
  organisationId: string | null
}
async function requireAdmin(): Promise<AdminCtx | { error: string }> {
  const supabase = await createClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return { error: 'Not authenticated' }
  const { data: { session } } = await supabase.auth.getSession()
  const jwtClaims: Record<string, any> = session?.access_token
    ? JSON.parse(atob(session.access_token.split('.')[1]))
    : {}
  const role: string = jwtClaims['user_role'] ?? ''
  if (!role || !['admin', 'safety_manager'].includes(role)) {
    return { error: 'Admin access required' }
  }
  const organisationId: string | null = jwtClaims['organisation_id'] ?? null
  return { supabase: supabase as any, user: { id: user.id }, role, organisationId }
}
```

**IMPORTANT DEVIATION FROM THE ANALOG:** `departments.ts` (Phase 25) decodes the JWT with raw `JSON.parse(atob(...))`, which is the exact anti-pattern CLAUDE.md's 2026-06-26 learning fixed elsewhere (`atob` ≠ Base64URL, throws on non-ASCII claim bytes). **Do NOT copy that line verbatim.** Use `src/lib/supabase/jwt.ts`'s `parseJwtPayload(token)` instead:
```typescript
// src/lib/supabase/jwt.ts — USE THIS, not atob directly
import { parseJwtPayload } from '@/lib/supabase/jwt'
const claims = parseJwtPayload(session.access_token)
const organisationId = claims['organisation_id'] as string | null
```
Every new agent-layer server action/route reading `organisation_id` from a token MUST use `parseJwtPayload`, never `atob` directly (this applies to `publish-hook`, `synthesis-sweep/route.ts`, and `agent-layer.ts` alike — the existing `publish/route.ts` and `departments.ts` both still use raw `atob`/JSON.parse and are legacy instances of the pre-fix pattern, not the target to imitate).

**Service-role write self-enforcement pattern** (from `departments.ts` assign* actions, per CLAUDE.md 2026-06-15): every `createAdminClient()` write in `agent-layer.ts` / `synthesis.ts` must include `.eq('organisation_id', callerOrg)` on the read/update side, and set `organisation_id: organisationId` explicitly on insert — never trust that service-role scoping happens automatically.

## Shared Patterns

### Org-scoped append-only tables (no authenticated write policy)
**Source:** `supabase/migrations/00038_phase23_schema.sql`, `00039_sop_image_annotations.sql`
**Apply to:** `sop_agent_metadata`, `block_agent_metadata`, `agent_memory`, `agent_learning_proposals`, `sop_voice_qa_log`
- Direct `organisation_id = current_organisation_id()` SELECT policy only, zero cross-table `exists()` subqueries.
- No INSERT/UPDATE/DELETE policy for `authenticated` — all writes via `createAdminClient()`.

### Service-role write org self-enforcement
**Source:** CLAUDE.md 2026-06-15 / 2026-06-26 learnings + `src/actions/departments.ts` assign* actions
**Apply to:** every write in `synthesis.ts`, `agent-layer.ts`, the publish-hook, the synthesis-sweep route, the voice-query write path.
- `createAdminClient()` bypasses RLS — the caller MUST filter/insert with `organisation_id` explicitly on every path (this exact class of bug shipped twice before in this codebase).

### JWT org-claim decoding
**Source:** `src/lib/supabase/jwt.ts` `parseJwtPayload()`
**Apply to:** every new route/action reading `organisation_id`/`user_role` from the session token.
- Never `atob(token.split('.')[1])` directly (breaks on non-ASCII claim bytes) — the existing `publish/route.ts` and `departments.ts` still have the old pattern; do not propagate it into new agent-layer code.

### Lazy external-API client singleton
**Source:** `src/lib/parsers/verify-sop.ts` `getAnthropic()`
**Apply to:** `voyage-client.ts`'s `getVoyageClient()`.
- `let client: T | null = null` + construct-on-first-call — never at module top-level (avoids throwing during Next.js build/static analysis when the API key is unset).

### Model ID as shared, env-overridable constant
**Source:** `src/lib/parsers/verify-sop.ts` `VERIFY_MODEL` pattern (CLAUDE.md 2026-06-02 model-rot learning)
**Apply to:** `EMBED_MODEL`, `SYNTHESIS_MODEL` in `model-constants.ts` — never hardcode the literal model string inline anywhere else.

### Fire-and-forget hook off a frozen gate
**Source:** `src/app/api/sops/[sopId]/publish/route.ts` step 4 (video auto-queue)
**Apply to:** the publish→synthesis trigger — `.catch()` + `console.error`, never `await`, never touches response shape or the frozen publish gate (steps 1-3).

### Injectable seam for unit-testable service-role writes
**Source:** `src/lib/ai-fields/approval.ts` `AdminInsertFn`
**Apply to:** `createLearningProposal` and any other agent-layer write that needs a fast, DB-less unit test.
