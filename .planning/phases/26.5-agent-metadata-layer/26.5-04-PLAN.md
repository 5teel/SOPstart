<objective>
Build the two pieces that make the layer non-dead: the proposal lifecycle (create-with-evidence / approve / decline + free memory writes) and the synthesis pipeline itself (embed + tag/entity + memory + assessment + evidence-backed proposals). This is infrastructure only — no flagship capability (D-13); the pipeline just populates the tables so the queue/feed/assessment are real, not permanently-empty UI (D-14 payoff).

Purpose: D-04 says regenerate on publish; D-07/D-08 define the proposal-vs-memory split; D-12 defines the per-SOP assessment; D-16 pins Haiku. The proposal path reuses the X-03 `AdminInsertFn` injectable seam so it is unit-testable without a live DB, and always-pending (no low-stake auto-apply — learning proposals are always admin-reviewed). The synthesis wrapper must fail loud-but-non-fatal so an all-error state is observable (Pitfall 5 / the 2026-06-02 VERIFY_MODEL incident).

Output: `src/lib/ai-fields/agent-proposals.ts`, `src/lib/agent-layer/synthesis.ts`, live proposal-evidence + synthesis-pipeline specs.
</objective>
