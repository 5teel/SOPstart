# Phase 26.5 Plan 05: Publish-Route Synthesis Hook + Backfill Script Summary

**One-liner:** Publish now fires `triggerAgentSynthesis` as one additive, non-blocking line after the frozen gate succeeds (byte-scoped diff, response shape untouched), and `scripts/backfill-agent-metadata.mjs` populates the agent-metadata layer for every already-published SOP across every org via the real `synthesizeSop` pipeline, capped per-org as a cost guardrail.

## What Was Built

**Task 1 — `src/app/api/sops/[sopId]/publish/route.ts`:**
- Added one import (`triggerAgentSynthesis` from `@/lib/agent-layer/synthesis`) and one call, placed immediately after the existing step 4 video auto-queue block, before the response is returned: `triggerAgentSynthesis(sopId, organisationId)`.
- No `await`, no `.catch` chain at the call site (Plan 04's `triggerAgentSynthesis` is void-returning and already wraps `synthesizeSop(...).catch(...)` internally — chaining `.catch()` on a `void` return is a TypeScript type error, so the call is bare by design).
- `git diff` on the route is scoped to exactly the import line + the 5-line comment+call block; steps 1-3 (frozen gate: section-approval check, verify-checklist gate, publish status flip) and the existing video auto-queue call are untouched. Response body remains `{ success: true, pipelineAutoQueued }`.

**Task 2 — `scripts/backfill-agent-metadata.mjs`:**
- Loads `.env.local` (same loader shape as `apply-phase26.5-migration.mjs`), then dynamically imports `synthesizeSop` and `createAdminClient` from the real TS lib modules (dynamic `import()` used specifically so `.env.local` is populated before `model-constants.ts`'s module-level `process.env.EMBED_MODEL`/`SYNTHESIS_MODEL` reads execute).
- Iterates every row in `organisations`, then every `sops` row with `status = 'published'` in that org, and calls `synthesizeSop(sop.id, org.id)` sequentially and awaited (a manual one-off batch job, not a per-request fire-and-forget path).
- Per-org cap `MAX_SOPS_PER_ORG` (default 200, override via `BACKFILL_MAX_SOPS_PER_ORG` env var) — SOPs beyond the cap are logged as skipped, not processed, bounding worst-case AI-call volume per run (T-26.5-05-04).
- Prints a per-org progress line (`[org] N published SOP(s) — processing X, SKIPPING Y (per-org cap Z)`), a per-SOP `OK`/`FAIL` line, and a final `{orgs, sopsProcessed, sopsSkipped}` JSON summary.
- Run via `npx tsx scripts/backfill-agent-metadata.mjs` (not plain `node` — the script imports `.ts` source files by relative path, which requires tsx's loader; plain Node has no TypeScript/path-alias resolution). The actual production run against the live DB is a manual, human-run step (Manual-Only Verification) — this plan only had to make the script runnable and correct.
- `tests/phase26.5/backfill-coverage.spec.ts` needed no code changes — its Wave-0 stub already auto-discovers any file under `scripts/` matching `/backfill/i` whose contents match `/agent|metadata|embed/i`, and asserts it references `'published'` and `synthesis|triggerAgentSynthesis`. Both assertions now pass live against the new script; the seeded-DB row-count test remains `test.fixme` (manual/integration, as scoped by the plan).

## Deviations from Plan

**1. [Rule 1 - Bug avoidance] Called `triggerAgentSynthesis` without a `.catch` chain at the call site**
- **Found during:** Task 1
- **Issue:** The plan's action text and `26.5-PATTERNS.md` both specify `triggerAgentSynthesis(sopId, organisationId).catch((err) => ...)`, but Plan 04 (26.5-04-SUMMARY.md) already implemented `triggerAgentSynthesis` as a `void`-returning function that internally does `synthesizeSop(...).catch(err => console.error(...))`. Chaining `.catch()` on a call that returns `void` is a TypeScript compile error.
- **Fix:** Called `triggerAgentSynthesis(sopId, organisationId)` bare, relying on its internal self-catch (already verified by `synthesis-pipeline.spec.ts`'s "Pitfall 5" test, which asserts the function body contains `.catch(` and never `throw`s). The live D-04 test in the same spec file only asserts the publish route contains the string `triggerAgentSynthesis` and does not contain `await triggerAgentSynthesis` — both satisfied.
- **Files modified:** src/app/api/sops/[sopId]/publish/route.ts
