### WR-02: No proposal dedupe — duplicate pending proposals per synthesis run

**Files modified:** `src/lib/ai-fields/agent-proposals.ts`, `tests/phase26.5/proposal-evidence.spec.ts`

### WR-03: Sweep starvation + infinite retry of failing SOPs

**Files modified:** `src/app/api/agent-layer/synthesis-sweep/route.ts`, `src/lib/agent-layer/synthesis.ts`
**Commit:** 1457e8b
**Applied fix:** (1) `findStaleSops` orders by `updated_at` desc before the 100-row window (deterministic; recently-active SOPs prioritised). (2) `synthesizeSop`'s error-path upsert stamps `regenerated_at` — a persistently-failing SOP leaves the stale set instead of re-billing Voyage/Anthropic every 5 minutes forever; `hasNewerSignal`/republish still re-flag it for retry. Known ceiling documented in-code: >100 published SOPs beyond the window need a trigger-maintained `last_signal_at` column.

### WR-04: `allRunsErrored` vacuously true on empty `job_status`

**Files modified:** `src/lib/agent-layer/signals.ts`
**Commit:** 363b4aa
**Applied fix:** A run only counts as errored when `Object.values(run.job_status ?? {})` is non-empty AND all `'error'` — empty/missing `job_status` → false, exactly the review's suggested guard.

### WR-05: Backfill FAIL branch was dead code — all-failing runs printed 100% OK

**Files modified:** `src/lib/agent-layer/synthesis.ts`, `scripts/backfill-agent-metadata.mjs`
**Commit:** d08575f
**Applied fix:** `synthesizeSop` now returns `SynthesisResult` (`{ ok: true } | { ok: false; error }`) while still never throwing (fire-and-forget callers unchanged — `.catch` wiring preserved, synthesis-pipeline spec still green). Backfill checks the result, counts `sopsFailed` separately from over-cap `sopsSkipped`, prints the real error per FAIL line, and exits 1 when `sopsFailed > 0`.

### WR-06: Agentview fetch chain had no `.catch` — failures rendered as "No synthesis run yet"
