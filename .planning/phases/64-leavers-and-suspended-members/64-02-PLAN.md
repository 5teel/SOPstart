## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → server action (`src/actions/members.ts`, auth.ts) | every `'use server'` export is a public POST endpoint taking a client-supplied member id |
| server → service role (state.ts, paused.ts, auth.ts admin reads) | bypasses RLS; scope must come from the session |
| server → auth sessions (revoke_user_sessions rpc) | ends another user's sessions |
