## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → `recordObservation` / `signOffCompletion` payload | Untrusted `overrideReason` crosses here; a client-supplied override flag must never exist |
| authenticated PostgREST → `sop_observations` INSERT | A raw REST call bypasses every server action; only RLS stands here |
| worker self-read on `sop_observations` | The observed worker can read `override_reason` via the existing OBS-02 self-read branch |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
