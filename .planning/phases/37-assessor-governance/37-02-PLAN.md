<objective>
Add the one pure predicate this phase gates on: "is this person themselves signed off on this exact SOP", derived entirely from existing evidence tables via the Phase 35 classifier and the Phase 36 lineage resolver.

Purpose: D-01 makes assessorship 100% derived — there is no designation table and there never will be one. That only holds if there is exactly ONE place the derivation happens. A bespoke "has a sign-off" check inlined in the two gated actions would drift from the ladder the moment the `needs_support` reset or the lineage widening changes, which is the drift class CLAUDE.md's 2026-06-05 learning is about.
Output: `isSignedOffAssessor` plus behavioural unit tests that run in the already-registered `phase35-unit` project.
</objective>
