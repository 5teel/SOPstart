<objective>
Gate the completion sign-off — the strongest competence-advancing record — on the same derived assessorship, widen the role array so the override path is reachable for admins, and surface the blocked/override states in the existing sign-off bar.

Purpose: D-03 is explicit that leaving sign-offs ungated would let a non-assessor bypass the observation gate via the stronger record. And Pitfall 2 is a real trap: `signOffCompletion` currently hard-excludes `admin`, so building a perfect override path without widening that array leaves D-06 unreachable on this surface no matter how good the gate is.
Output: gated `signOffCompletion`, server-computed assessor props, blocked/override UI, and `assessor-ui-signoff.spec.ts` flipped live.
</objective>
