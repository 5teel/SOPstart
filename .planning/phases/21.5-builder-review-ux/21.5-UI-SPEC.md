## Spacing Scale

Source: sketch-findings-SOPstart `references/design-tokens.md` + sketch HTML.
Base unit is 4px; grid unit (flow canvas) is 20px.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, flag badge internal padding, stepper chip vertical padding |
| sm | 8px | Nav row vertical padding, zone-head padding-block, orientation strip vertical padding |
| md | 16px | Zone-body padding, card internal padding, orientation strip horizontal padding |
| lg | 24px | Desktop card padding, section gap |
| xl | 32px | Layout gap between major zones |
| 2xl | 48px | Top bar height; not used on Review Station surfaces otherwise |
| 3xl | 64px | Not used in Review Station surfaces |

**Phase-specific values (all multiples of 4):**
- Zone-body padding: **16px** (md)
- Nav row padding: **8px** vertical (sm)
- Action bar padding: 12px 16px (spans zones 2+3; from sketch `.actionbar`)
- Top bar height: **48px** (2xl)
- Stepper chip padding: **4px** 12px (xs vertical)
- Orientation strip padding: **8px / 16px** (sm / md)

Audited: every spacing/gap/padding/margin value in this document is a multiple of 4. Border-widths (1px / 1.5px hairlines) are exempt as stroke widths, not spacing.

## Typography

Source: LOCKED — `sketch-findings-SOPstart/references/design-tokens.md`.

**Note on weights:** This phase uses 3 weights (400, 500, 600). This is an intentional,
locked inheritance from the sketch-findings-SOPstart design tokens, which load Inter at
400/500/600. Future checkers must not flag this as a violation — it is project-canon.

| Role | Font | Size | Weight | Line Height | Usage |
|------|------|------|--------|-------------|-------|
| Body prose | Inter | 14px | 400 | 1.55 | Step card body text (worker-facing copy), zone 3 source doc body |
| UI label (mono) | JetBrains Mono | 12px | 500 | 1.3 | Zone headers, orientation strip prose, action bar buttons, flag card descriptions, stepper chips, re-run button |
| Micro label (mono) | JetBrains Mono | 10px | 500 | 1.3 | Status pills, kind labels, key hints, page refs, meta pills, source hint, flag severity badges, stepper arrow glyph, top bar subtitle, publish gate reason span |
| Step heading | Inter | 17px | 600 | 1.2 | Step card h2 (worker-visible step title) and Publish stage heading (weight 700 to distinguish display role) |

**Consolidated size mapping (from sketch pixel values → locked tokens):**

| Sketch pixel | Locked token | Rationale |
|-------------|-------------|-----------|
| 9px, 10px, 11px | **10px** | Micro labels — sub-UI chrome, badges, hints, pills |
| 12px | **12px** | UI labels — descriptions, control labels, mono prose |
| 13px, 13.5px | **14px** | Body prose — human-readable step content |
| 17px | **17px** | Step heading — zone-2 card title; also Publish stage heading at weight 700 |

No 11px, 13px, 13.5px, or 20px values appear anywhere in this document.
The final size scale is exactly: **10 / 12 / 14 / 17px**.

**Top bar SOP title:** 12px / weight 600 / JetBrains Mono
**Top bar subtitle (version):** 10px / weight 400 / JetBrains Mono / color `--ink-500`
**Flag card description:** 12px / line-height 1.45 / JetBrains Mono; `<b>` elements switch to Inter
**Action bar buttons:** 12px / weight 600 / JetBrains Mono

**Typography rule:** Technical content (IDs, step numbers, measurements,
timestamps, tool names, type labels) — JetBrains Mono by default.
Long-form human-readable prose (step descriptions, hazard explanations,
flag descriptions) — Inter via `.prose` class on the content wrapper.

Text transform: uppercase + `letter-spacing: 0.08em` on pills and zone labels.

block back to unverified state. No confirmation dialog; the action is
immediately reversible by re-verifying.

## Safety Gate Invariants (UI Contract)

Source: SPEC Requirement 10 + D-21-07.

1. **No bulk-verify affordance.** No "Verify all", "Approve all", "Select all",
   or "Trust score skip" button, checkbox, or control may appear anywhere
   in the builder surface. `tests/lint/no-bulk-verify-ui.spec.ts` enforces this.

2. **Publish button state contract:**
   - `disabled={!isReady}` — same as `VerifyProgressIndicator` today
   - `cursor-not-allowed` when disabled
