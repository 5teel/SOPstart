## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Spec Test 2 false-positive on JSDoc comment mention**

- **Found during:** First spec run
- **Issue:** Test 2 asserted `.not.toContain('VerifyProgressIndicator')` on the full file source. The shell's JSDoc comment block says "No VerifyProgressIndicator or bulk-verify affordance mounted here." — this is documentation, not code. The raw `.toContain` matched the comment, failing the test.
- **Fix:** Filtered comment lines (those starting with `//`, `*`, `/*`) before applying the assertion, matching the pattern used by `no-bulk-verify-ui.spec.ts` itself.
- **Files modified:** `tests/builder/builder-review-flow.spec.ts`
- **Commit:** 132335f (incorporated into Task 2 commit)

**2. [Rule 3 - Blocking] phase21.5-stubs testDir scope**

- **Found during:** Task 2 spec registration
- **Issue:** The plan specified `testMatch: /(block-type-labels|builder-review-flow)/` for `phase21.5-stubs` without a `testDir`. Playwright's default `testDir` is `./tests`; `block-type-labels.test.ts` lives under `src/lib/builder/__tests__/` and was not discovered.
- **Fix:** Added `testDir: '.'` to the project so both `tests/` and `src/` subtrees are searched; the regex then selects only the two target files.
- **Files modified:** `playwright.config.ts`
- **Commit:** 132335f
