## What Was Built

`PublishStage.tsx` — a new controlled/presentational component exported as `PublishStage`. It renders:

1. Stage heading "Publish this SOP" (Inter 17px weight 700, `--ink-900`)
2. Subtext (Inter 14px, `--ink-500`)
3. Progress summary with verified count — only when `hasSourceDoc === true` (green checkmark + "N steps verified", mono 12px uppercase `--accent-ok`)
4. Inline amber strip `data-testid="publish-blocked-reason"` when `!isReady` — "N of M steps left to verify before you can publish" in `#c2410c` on `#fff7ed` background — always in DOM when blocked, removed when ready
5. Gated publish button `data-testid="publish-button"` — disabled when `!isReady || publishing`; blocked style uses `--steel-700` / `--ink-500` / `cursor-not-allowed`; ready style uses `--brand-yellow` / `--ink-900` / weight 700
6. Publish error banner `data-testid="publish-error-banner"` with `role="alert"` and click-to-dismiss matching `BuilderWithSourceViewer` markup exactly
7. "← Back to Review" text link (mono 12px, `--ink-500`) — rendered only when `hasSourceDoc === true`

No `fetch`, no Supabase import, no `/publish` literal — purely invokes the `onPublish` callback prop (Req 10 callback-chain preserved).
