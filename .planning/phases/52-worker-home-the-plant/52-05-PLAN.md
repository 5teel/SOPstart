Output: live `plant-home.eval.ts`, `run-evals.mjs --workers=1`, `52-EVAL.md`, signed-off `52-VALIDATION.md`, learnings logged if any fix needed more than one attempt.

Why `--workers=1`: `npm run eval` runs every eval file, in parallel by default. `site-editor.eval.ts`'s `beforeAll` deletes the eval-site org's layout (cascading machines and `sop_machines`) — run concurrently with the plant eval, which reads that same org, it would delete the scene mid-test. Serial runs remove the race; the plant eval's `beforeAll` re-creates whatever it needs, so file order does not matter.
</objective>
