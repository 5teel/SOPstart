Discretion calls (CONTEXT § Claude's Discretion):
- The camera lives INSIDE `PlantStage` (it owns the measured size) and is driven from outside through a `ref` handle (`fit`, `flyTo`, `fitMachines`) — React 19 `ref` as a prop, no forwardRef.
- Labels and pins are counter-scaled by `1 / view.s` so the pin is a real 26 px circle and labels stay legible at the fit scale (~0.5 on a 2K scene). The sketch let them scale with the world; at 1440 px that renders the count in ~6 px type.
- Zone colour: a department's own `colour` unless it is the column default `#3b82f6` (00035 — every department without an explicit colour carries it), then the contract triple by name (Forming → `var(--accent-voice)`, General → `var(--accent-measure)`, Engineering → `var(--accent-inspect)` — the exact hexes of the contract, already tokens), then the next theme accent by index (D-12). The logic lives in `scene.ts` (plain lib code), so component code carries no hex.
- Pin bob: a plain `.plant-pin-bob` class + keyframes in `globals.css` next to the other animation classes, with the existing reduced-motion block — no new Tailwind utility family to risk compiling to nothing (2026-09-28).
