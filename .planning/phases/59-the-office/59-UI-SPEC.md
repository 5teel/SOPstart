## Pane Frame

**Focal anchor per tab (checker recommendation, picked):** Inbox — the first row's severity dot and title; Decisions — the table header then the newest row's **What** column; People — the **Invite** button then the first row's email; Access — the lens's own first machine row. Everything else is quieter than that anchor.

The Office is the detail pane (`data-testid="shell-detail"`) of `/?place=office[&tab=…]`. It is never a page (D-01). The pane body is one lazy module, `OfficePane` (admin shell, and a second lazy import for the supervisor shell — A-11).

```
┌ shell-detail (overflow-y-auto, bg-paper) ──────────────────────────────┐
│ header (sticky top-0, bg-paper, px-4 pt-4 pr-16)                  [ X ] │  ← Close stays top-right
│   Office                                         (text-lg semibold)     │
│   ┌ segmented tab control ─────────────────────────────┐                │
│   │ Inbox 3 │ Decisions │ People & roles │ Access       │                │
│   └─────────────────────────────────────────────────────┘                │
│   (inbox only) chips: All 7 · No owner 2 · Overdue 1 · Sign-off 3 …     │
│   receipt slot (reserved, min-h-9): ✓ Signed off · logged in the …      │
├────────────────────────────────────────────────────────────────────────┤
│ body (px-4 pb-8; Access: px-2) — one of the four tab bodies             │
└────────────────────────────────────────────────────────────────────────┘
```

### Width per tab (SHL-06, D-02)

| Tab | Pane width at lg+ (≥1024) | Classes |
|-----|---------------------------|---------|
| Inbox | 400 px (normal) | literal `lg:w-100` stays in `ShellFrame.tsx` (pinned by the Phase 57 shell spec) |
| Decisions | wide | `lg:w-[58%] lg:min-w-140` (58 % of the screen, never under 560 px) |
| People & roles | wide | same |
| Access | wide | same. **(picked)** Access does not claim more than the wide width: the lens scrolls horizontally inside its container (`overflow-x-auto`) when the pane is narrower than the wiring needs (about 720 px: two 320 px columns, 40 px gap, 20 px bay padding). At a 1440 screen the pane is about 835 px so it fits; the map never leaves |

| Rule | Value |
|------|-------|
| Wide is derived, not stored | `wide = room office AND tab in {decisions, people, access}` computed from the one place state; the width class is the only visual change (F-13) |
| Width change | **(picked)** instant, no CSS width transition. A transition would fire the stage `ResizeObserver` every frame and re-fly the camera on each one; the existing camera flight already animates the re-centre once, after the width settles |
| Map | stays live and re-centres on the Office on every width change (existing `PlantStage` observer; 0×0 stage guarded). At 1440 the map is about 349 px wide in the wide state — acceptable by contract |
| Tab switch | `placeKey` includes the tab so the pane remounts and the camera re-flies to the Office once; query caches persist so a return to a tab is instant |
| Back from a focus screen | `focusHref(id, { from: 'office' })` returns to `/?place=office` (the Inbox), not to the tab the user left. **(picked)** — `from` carries the room token only |
| Close / Esc | Close (`X`, existing) and Esc return to the overview and refit. **Esc order (A-12): lightbox → any dialog/sheet → owner popover → an expanded row (collapses it) → leave the Office.** A layer that consumes Esc calls `preventDefault`; the shell handler ignores defaulted events and ignores Esc while any `[aria-modal="true"]` exists |
| Header | `sticky top-0 z-10 bg-paper border-b border-ink-200`; the Close button is raised one level (`z-20`) so the header never paints over it. The header keeps `pr-16` (64 px) clearance for Close |
| Tab control | below, "Segmented tab control" |
| Loading | each tab shows a skeleton, never a spinner-only pane: three `h-18 rounded-lg bg-ink-100 animate-pulse` rows (Inbox, Decisions), four rows for People, a 4-bar block for Access (the lens brings its own). Static under `prefers-reduced-motion` |
| Error | one line `text-ui text-ink-700` + "Try again" secondary button (`min-h-tap`) — copy in the Copywriting Contract |

## Spacing Scale

Declared values (multiples of 4); Tailwind numeric scale.

| Token | Value | Usage here |
|-------|-------|------------|
| xs | 4px | chip inner gap, segment track padding (`p-1`), expanded-row left border (`border-l-4`) |
| sm | 8px | icon gaps, row inner gaps, chip padding, between chips |
| md | 16px | pane padding (`p-4`), row horizontal padding, panel padding, gap between panel sections |
| lg | 24px | dialog padding (`p-6`), gap between tab header and body on wide tabs |
| xl | 32px | bottom padding of a tab body (`pb-8`) |
| 2xl | 48px | empty-state vertical padding (`py-12`) |
| 3xl | 64px | header right clearance for Close (`pr-16`) |

Row vertical padding `py-3` (12px) is a multiple of 4.

Exceptions (all existing tokens or contract values): tap targets `min-h-tap` 44 on every control; `lg:w-100` = 400 and `lg:min-w-140` = 560 (contract widths); photo thumbs `size-18` = 72; severity dot `size-3` = 12; filter chips `h-9` = 36 — **(picked)** a declared exception: chips are secondary desktop-only filters and the existing inbox chips are already 36; the Office is a desktop surface (the glove 60 / row 72 ladder from the worker screens does not apply). Skeleton rows `h-18` = 72; step list `max-h-80` = 320 (scrolls inside the panel). Access container uses `px-2` (8) so the wiring gets 726 px of a 742 px pane at 1280.

**Contrast rule (picked):** amber `accent-decision` on white is about 3.2:1, below AA for small text. So amber is never used as text colour at 11–13 px: the warn chip and the "No owner" tint carry colour in the **fill, border and icon** while the words stay `text-ink-900` semibold. Escalate red (about 4.8:1) and measure blue may be used as text.

Severity (unchanged from Phase 54): No owner → **bad**; Stuck → **bad**; Overdue → **warn**; Sign-off → **warn**; Approve (my turn) → **info**; No SOP on a machine → **grey**; Owner role gone → **grey**. Rows sort worst-first (existing `deriveInbox`).

A SOP that is both unowned and overdue is one row (worst severity, **Assign owner**); after it is assigned the refetch returns it as an Overdue row.

### Clearing a row (D-04)

| Step | Behaviour |
|------|-----------|
| 1 pending | on press the button shows `Loader2` + a present-tense word ("Assigning…", "Signing off…"), is disabled, the row drops to `opacity-60`. No other row is locked |
| 2 success | the **receipt slot** in the header shows the receipt (below). The row stays dimmed until the refetch lands — the refetch decides whether the row is gone (collapse) or comes back with a new kind (re-render in place with the new chip and button). The shell cache is patched (Office pin and Inbox count decrement) without re-signing the scene image (F-02) |
| 3 collapse | a cleared row collapses over 200 ms (height + opacity, `transition-all duration-200`); under `prefers-reduced-motion` it is removed instantly |
| 4 focus | focus moves to the next row's button, else the previous, else the empty-state heading (`tabIndex={-1}`) |
| 5 failure | the row un-dims and shows an inline error line under the detail (`text-ui text-accent-escalate`, `role="alert"`) with the server's plain message; the button re-enables |

**Receipt slot (picked):** a reserved `min-h-9` line under the chips (and under the tab control for non-Inbox tabs), so nothing shifts when a receipt appears (the 58 "reserved slot" idiom). `text-ui text-ink-700`, `Check` icon `text-accent-ok`, `role="status"` `aria-live="polite"`. Holds until the next action, a tab change, or 10 s. If the ledger write failed (`logged: false`) it reads in `text-accent-escalate` with the failure copy — the UI says "logged" only when it was.

### Empty state (D-05)

Centred, `py-12 px-4`. `CheckCircle` `size-12 text-accent-ok`; heading `text-lg font-semibold` **"Nothing needs you. That's the goal."** (`data-testid="office-empty"`); beneath it, one line `text-ui text-ink-500` (`data-testid="office-cleared-today"`): "{n} cleared today." (1 → "1 cleared today."; 0 → "Nothing was waiting today."). The count is the caller-org's person-made ledger rows today (Pacific/Auckland). Not shown to supervisors.
Filtered-empty (a chip with no rows while the inbox is not empty): "Nothing under this filter." + "Show all" secondary button.
