Job spec template (Spike 003 pattern):
```typescript
export const JOB_B: ReviewerJob = {
  id: 'B',
  systemPrompt: `You are reviewing a structured SOP draft against its source document.
Report at MOST the top 5 omissions where safety-critical content from the SOURCE is MISSING from the DRAFT.
Each description ≤ 100 characters.
Output JSON array only.
Schema: [{severity, kind:'omission', source_quote, source_location_hint, missing_from, description}]`,
  maxTokens: 2000,
  parseResponse: (raw) => JSON.parse(raw).map(/* shape to ReviewerFlag */),
}
```

Job C pattern (D-21-11): one LLM call returns BOTH anchoring and alignment facets.
Output shape includes `photo_id`, `current_step_id`, `suggested_step_id` (anchoring,
SCP-AI-02) AND `alignment_concern: boolean` (image-step alignment, SCP-AI-03).

Job D pattern (table fidelity) — focuses on numerical preservation. System prompt
checks: dosages, torques, temperatures, pressures, voltages, time durations.

Job E pattern (terminology consistency) — needs the org's existing SOP vocabulary
as context. Pre-fetch top 50 distinct terms from `sop_steps.text` for the org and
inject as a "known vocabulary" block.
