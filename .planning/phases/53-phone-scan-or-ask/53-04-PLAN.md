<objective>
Build the phone home and put it on `/sops` below 1024px: the ask bar, the Now card (Walk it / Read), a floor picture that opens a department-grouped machine list, and today's list underneath as "Everything else".

Purpose: PHN-01 — on a 6-inch screen the worker never browses a drawing. The picture is a way into a plain list of machines; the list rows open the machine page 53-03 built. The Scan button is added by 53-05 together with the scan sheet it opens, so nothing here is a dead control.

Output: `NowCard` (optional `onShowMe`, `inline`) · `code` on `WorkerSiteMachine` · `MachineListSheet.tsx` · `PhoneHome.tsx` · the `/sops` phone seam · a phone-home forbidden-marker group · a clean build.

Seam decision (deviation from the literal RESEARCH Q1 wording, recorded): CONTEXT D-01 says both "`enabled` simplifies to `!isAdmin`" and "Admin sessions on a phone get the same phone home as workers". `!isAdmin` alone would never fetch the site for a phone admin, so the second sentence could not hold. The query stays ONE shared `['site-worker']` fetch for both viewports (the substance of Q1) with `enabled: wantsPlant || wantsPhone`, where `wantsPlant = !isAdmin && viewport === 'desktop'` (52's line, unchanged) and `wantsPhone = viewport === 'mobile'`. Known cost: `useViewport()` starts at 'mobile' on first paint, so a desktop admin's first load makes one site read that is then unused — `ponytail:` comment it; a "viewport resolved" flag on `useViewport` is the upgrade if it ever matters.
