# Phase 21.6 Plan 03: Tree Rail — Section ▸ Steps Spine Summary

**One-liner:** Custom left-rail tree with `deriveStepTree` (flat → Section ▸ Steps), `reorderSections` drag, and E6 display-only "Reference images" relabel — all read-only over `layout_data`.

## What Was Built

Four new `'use client'` components under `src/components/admin/builder/`, each with the D-21-09 isolation header:

**Task 1 — Row atoms (TreeSectionRow, TreeStepRow, TreeBlockRow):**

- `TreeSectionRow.tsx` — draggable section parent row: `GripVertical` (14px ink-500), section title (Inter 13px/500), `ChevronDown/Right` collapse toggle. Active state: `border-left: 2px solid var(--accent-step)` + `bg-paper-2`. Min 40px. Props: `section`, `isActive`, `isExpanded`, `onToggle`, `onSelect`, HTML5 drag handlers. `data-testid="tree-section-row"`, `role="button"`, `aria-expanded`, `aria-label`.

- `TreeStepRow.tsx` — numbered step child row mirroring NavRow.tsx anatomy: 16px circle dot (empty, ink-300 border), 74px kind pill (`getPillStyle` verbatim from NavRow), `Step {N}` prefix + 60-char truncated preview. `paddingLeft: 24px`. Active: `border: 1px solid var(--accent-step); background: #eff4ff`. `data-testid="tree-step-row"`, `tabIndex={0}`, `aria-label="Step N: preview"`. Exports `PuckItem` interface.

- `TreeBlockRow.tsx` — block grandchild row: 60px pill (narrower than step to signal hierarchy), JetBrains Mono 12px/400 ink-500 label, 40-char truncated preview, `paddingLeft: 40px`, min 28px. Same `getPillStyle`. All labels via `humanizeBlockType`. `data-testid="tree-block-row"`.

**Task 2 — BuilderTreeRail.tsx (root rail):**

- `STEP_TYPES = new Set(['StepBlock', 'StepWithPhotosBlock'])` — step classifier
- `deriveStepTree(content)` — pure read of `layout_data.content[]`; returns `TreeNode[]` with `{ kind: 'step', item, stepNumber, children }` (D-01) or `{ kind: 'flat', item }` (D-02); preFlight nodes unshift at front
- E6 display override: `getDisplayLabel()` — when `item.type === 'HeadingBlock'` and `String(item.props?.text ?? '').startsWith('Unanchored figures')` → shows `'Reference images'`; `layout_data` NEVER written
- `reorderSections` folded from SectionListSidebar: optimistic setState + commitReorder + revert-on-error + red error strip
- `useGetPuck()` captured at component root for Plan 04 `insertBlock` dispatch
- `insertBlock()` helper wired to `puck.dispatch({ type: 'insert', componentType, destinationIndex: afterIndex+1, destinationZone: 'root:default-zone' })`
- "SECTIONS" heading (JetBrains Mono 10px/600 uppercase ink-500)
- Collapsible sections via `expandedSectionId` state; active section expanded by default
- "Before first step" non-clickable header rendered when section has steps AND preFlight blocks
- Empty section state: `This section has no content yet. Use ＋ Add to add your first step.`
- `＋ Add step or block` placeholder (dashed border 32px, `data-testid="add-control"`) — `// AddMenu wired in Plan 04`
- Width: `w-[240px] lg:w-[280px]`; `data-testid="builder-tree-rail"`; `aria-label="SOP builder — sections and steps"`
