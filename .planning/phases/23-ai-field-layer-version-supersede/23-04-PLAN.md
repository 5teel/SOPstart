<objective>
Build the AI WRITE layer (AFL-AI-02) with the tiered approval model: `gateWrite` (D-01/D-02 — low-stake auto-applies; high-stake on published SOPs + member roles requires approval), the `POST /api/ai-fields/write` v5.0-agent entrypoint, the Accept/Reject server actions, and the inline diff affordance (D-03 — no central queue). This is the privilege-escalation surface: an auto-applied write must NEVER reach a high-stakes published-SOP/member-role field.

Purpose: AFL-AI-02 + the D-01/D-02/D-03 approval model — the safety boundary of the whole AI field layer. The gate is the SINGLE write path; descriptor.write() is never called directly by routes. High-stake writes become persisted pending proposals reviewed inline at the field.
Output: approval gate + write route + Accept/Reject actions + inline diff component + gate unit tests.
</objective>
