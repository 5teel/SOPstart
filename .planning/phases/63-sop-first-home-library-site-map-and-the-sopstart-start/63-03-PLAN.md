<feature>
  <name>Isometric projection, shape descriptors and automatic site layout</name>
  <files>src/lib/library/iso.ts, src/lib/library/iso-layout.ts, tests/phase63/iso-layout.spec.ts</files>
  <behavior>
    - project(x, y, z) equals the sketch's `P()` (TS 20, cos 30 0.866): project(1, 0, 0) = [17.32, 10]; project(0, 0, 1) = [0, -20]
    - boxFaces returns three polygons (right, left, top) whose `role` is a token-role string (for example 'plate-top', 'plate-right', 'plate-left', 'steel-top', 'steel-side', 'steel-dark', 'accent-top', 'accent-side', 'paper', 'edge'); no descriptor carries a hex value or an rgb() string
    - glyph(kind, x, y) returns the descriptor list for each kind in FOOTPRINT (machine, conveyor, tank, rack, forklift, bench, board), porting the sketch's `entity()` shapes; every point is finite
    - layoutSite(areas: { id; count; kinds: ObjectKind[] }[]) returns { plates: { id, x, y, w, d }[], objects: { areaId, i, kind, x, y, cx, cy }[], ground: [x0, y0, x1, y1] }
    - for every n in {1, 3, 8, 12} areas and every count in {1, 6, 15, 40} objects per area: no two plates overlap (axis-aligned rectangles, gap >= 1 unit); every object footprint lies inside its plate's inner margin (0.8); every plate lies inside the ground; objects in one plate do not overlap
    - layoutSite is deterministic: the same input twice gives deep-equal output; input order of equal-sized areas is preserved (stable sort)
    - one area is centred on the ground; plate size grows with count (cell about 2.8 x 2.4 units plus 0.8 margin each side), minimum 5 x 4
    - viewFor(layout, null) bounds the ground and every plate's raised corners plus a 16-unit pad; viewFor(layout, areaId) bounds that plate with the sketch's pads (50 / 30 / 100 / 70); an unknown id falls back to the whole site
    - draw order helper `byDepth` sorts plates and objects by (x + y) ascending (painter's order)
  </behavior>
