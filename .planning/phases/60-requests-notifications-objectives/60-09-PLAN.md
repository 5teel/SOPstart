## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-60-40 | Elevation (worker or supervisor sets objectives) | objectives core | mitigate | role read from the session inside the core, so both paths share the gate |
| T-60-41 | Tampering (cross-tenant objective via a client subject id) | `setObjectiveCore` | mitigate | subject verified in the session org; every query org-filtered; no org parameter exists |

| T-60-43 | Repudiation (objective change not logged / logged twice) | actions | mitigate | one `recordDecision` per action after the core; agent writes logged once by `applyAiWrite`; registry + sweep |
| T-60-44 | Information disclosure (orphaned rows about a deleted SOP) | `deleteSop` | mitigate | three org-scoped deletes in the same function; spec asserts the filter |
