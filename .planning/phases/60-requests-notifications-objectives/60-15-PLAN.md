## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser client → `notifications` | own-row RLS read and the column-limited `read_at` update |
| stored `place` → navigation | a server-written path turned into `select()` or a router push |
| overview → `withdrawRequest` / `declineAsk` / `stopAsking` | POST-reachable actions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-60-62 | Spoofing / Tampering (open redirect through a place) | notification open | mitigate | `placeTarget` (fixed templates; anything else is the overview) plus the table CHECK; no full URL is ever followed |

| T-60-64 | Tampering (rewrite another person's notification) | mark-read | mitigate | RLS own-row update with `read_at` the only granted column (60-02, proven by the live probe) |
