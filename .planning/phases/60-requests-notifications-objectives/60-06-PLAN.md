| T-60-26 | Tampering (one worker removes a role's assignment for everyone) | `declineAskCore` | mitigate | claim requires `target_user_id` = caller; only the caller's individual row is deleted (A-03) |
| T-60-27 | Tampering (anyone stops someone else's ask) | `stopAskingCore` | mitigate | claim filtered on `raised_by_user` = caller unless the session role is admin / safety manager |
| T-60-28 | Tampering (half-written ask: a due SOP with no request, or a request with no due SOP) | `askToDoSopCore` | mitigate | assignment written first, request second, compensating undo on a failed request insert; spec pins the order and the undo |
