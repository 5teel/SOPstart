    - `isRefresherOverdue(dueIso: string | null, nowIso: string): boolean` — false when `dueIso` is null, otherwise `nowIso > dueIso` (both are ISO-8601 UTC strings, so lexicographic comparison is correct and matches the `latestOf`/`latestTimestamp` string-compare idiom already used in competency.ts and matrix.ts).
