## Kind mapping (D-02 as amended by A-02 and D-03) — the converter implements exactly this

| Registry type | Kind | Text | photo_required | image_paths |
|---|---|---|---|---|
| HazardCardBlock | hazard | `body`; prefix `title: ` when title is not `Hazard` / `Untitled hazard`; prefix `Critical: ` when severity is critical; empty body AND default title = FAILURE | false | — |
| PPECardBlock | ppe | title (when not `PPE Required`) then each item on its own line; items arrive as `string` or `{ item }`; zero items and no title = FAILURE | false | — |
| StepBlock | step | `text` (+ `tip` from a following Tip callout; also `warning`/`tip` props if present → hazard before / tip) | false | — |
| StepWithPhotosBlock | step | `text` | true (D-02) | each `photos[].src` that is a raw storage path |
| MeasurementBlock | check | `Check {label}: {min}–{max} {unit}` (+ `target`, + `hint`) — read props directly, the lenient converter drops tolerance | false | — |
| InspectBlock | check | `title` then each item label on its own line | true if any `requirePhoto` | — |
| DecisionBlock | check | `question` then `If {label}: …` per option, `(escalate)` on escalation options | false | — |
| SignOffBlock | check | `title` (+ acknowledgementText) + `(needs {requiredRole})` | false | — |
| CalloutBlock titled Warning / Caution (trimmed, case-insensitive) | hazard, placed BEFORE the step it follows (D-03) | `Warning: {body}` / `Caution: {body}`; empty body = FAILURE | false | — |
| CalloutBlock titled Tip | folded into the preceding step's `tip` (no row; counted); with no preceding step → step `Tip: {body}` | | | |
| CalloutBlock any other title | step (hazard/ppe if the section classifies so, D-04) | `{title}: {body}` | false | — |
| TextBlock | step (hazard/ppe if the section classifies so, D-04) | `content` | false | — |
| HeadingBlock | step | `text` | false | — |
| ZoneBlock | step | `label` (+ zoneType, notes) | false | — |
| EscalateBlock | step | `title` (+ reason) | false | — |
| ModelBlock | step | `3D model` + hotspot labels | false | — |
| PhotoBlock | step | caption ?? alt ?? `Take a photo` | true | `src` when a raw storage path |
| PhotoGridBlock | step | captions/alts joined | true | each `items[].src` |
| VisualBlock | step | captions/alts joined | true | each photo/diagram item `bakedSrc ?? src`; video items dropped with a count; all-video block = dropped with a count |
| VoiceNoteBlock | dropped with a count (no transcript field exists, A-02) | | | |
| any other type | FAILURE (unreadable) | | | |

Rows fallback (section with NULL `layout_data`): per `sop_steps` row in `step_number` order emit hazard(`Warning: warning`) then hazard(`Caution: caution`) then step(`text`, `tip`, `photo_required`, image_paths = that row's `sop_images.storage_path`s); a step-less section with `content` → hazard per non-empty line when `isHazardSection`, one ppe step with the lines when `isPpeSection`, else one step with the content. Source precedence: `layout_data` where present, rows otherwise (Claude's discretion, recorded per SOP as `layout | rows | mixed | empty`).
