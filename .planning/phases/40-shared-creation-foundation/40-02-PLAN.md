Order matters because a HEIC file's MIME is not always reported, so the type check must run after conversion, and the macro block must run before anything reads the file.

Carry the existing user-facing messages verbatim from `UploadDropzone.validateAndAddFiles` so the toast copy does not silently change: the macro message, the over-2GB video message, the over-50MB document message, the HEIC-conversion-failure message, and the unsupported-format message (update only the format list inside the unsupported-format message to match `INTAKE_HINT`).
