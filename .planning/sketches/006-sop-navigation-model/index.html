Variant A — Place tree. One library for everyone.

The left column is a single-select tree of where (department → machine/area). It can only mean one thing, so the "is this a menu or a multi-select" question can't arise. Who-you-are lives in one toggle (Mine / All), what-you-owe lives as a badge on the row, and admin facets are dropdowns on the toolbar because facets combine and a column can't say AND. Toggle View as above to see the same page for a worker and an admin — same layout, two extra controls.

Variant B — Search-first, no left column.

The strongest form of "the column shouldn't exist". Search is the primary control, Mine/All beside it, and department is a row of chips under the toolbar. Two columns: list and detail. Gains a wider list (long glass-forming titles stop truncating). Loses the browsable hierarchy — an operator who doesn't know the SOP's name has to scan chips instead of walking a tree.

Governance — its own page (admin only).

The Visy finding: nobody owns SOPs. This is the daily console for the person who has to. Every deck is a queue that drains, each row carries the one action that clears it, and the "all clear" state finally makes sense because the whole page is the queue. Nothing here is a filter over the library — "Drafts" lives here as unfinished work, and on /sops as a status facet, and those are different questions.
