# Sketch 001: Org Model Canvas

## Design Question
A new customer (Visy) needs to model their site — departments, the roles inside them, and the people in those roles (named, or left as role-descriptor vacancies) — fast enough that it feels like sketching, not data entry. Which structural metaphor gets them there?

## How to View
open .planning/sketches/001-org-model-canvas/index.html

## Variants
- **A: Column Builder** — departments as columns, roles as cards, people as chips; everything added in place (Trello-speed entry, no spatial layout to manage)
- **B: Node Chart** — a true spatial org chart on grid paper, same visual language as the SOP Flow tab; nodes selectable, positions meaningful
- **C: Outline Tree** — indented text-first roster; fastest keyboard entry, reads like a site list, zero layout decisions

## What to Look For
- Which one could a plant manager fill in for a 5-department site in under 10 minutes?
- Vacancy treatment: dashed chips ("Operator — night shift, unfilled") must feel like first-class citizens, not errors
- Variant B is the only one that doubles as the substrate for permission wiring (Sketch 002-A draws wires FROM these nodes) — if B loses here, 002 leans matrix/illuminate
- Role capacity counts (1/2, 3/4) — do they earn their place?
