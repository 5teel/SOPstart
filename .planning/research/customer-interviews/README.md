# Customer Interviews — Field Research

Primary-source customer conversations that should shape the SafeStart roadmap.

Each interview is filed as two paired documents:
- `YYYY-MM-DD-<org>-transcript.md` — Deepgram-transcribed verbatim record (with timestamps and speaker labels)
- `YYYY-MM-DD-<org>-findings.md` — structured analysis extracting domain context, pain points, feature requests, contradictions, and "act on this" items

## When to consult this folder

- Before spec/discuss/plan on any new phase — check whether a real customer voice has already informed the problem space
- Before locking a contentious UX decision (e.g. mobile vs desktop primacy, identity model, approval-chain design)
- When triaging backlog ideas — findings here have higher weight than speculative ideas
- When pitching: the verbatim quotes are gold for landing the "this is a real problem, not a guess" story
